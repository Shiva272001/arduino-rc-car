# 🤖 Arduino & Robotics Projects

Welcome to my **Arduino & Robotics Projects Repository**! 🚀

This repository contains my collection of **Arduino-based robotics, RC car, sensor, communication, and hardware projects**. It includes project reports, circuit details, sensor experiments, programming, and documentation.

## 📂 Projects & Reports

### 🚗 RC Car Projects
- **RC Car 4-Wheel** – Arduino-based 4-wheel remote-controlled car.
- **HC-05 Bluetooth RC Car** – Wireless RC car using Bluetooth communication.
- **KY-023 Joystick RC Car** – RC car control using a joystick module.
- **GY-271 Magnetometer** – Magnetometer integration and testing with an RC car.
- **MPU-9250 Gyroscope/IMU** – Gyroscope and motion-sensing experiments for robotics.
- **MPU-9250 + GY-271** – Combined IMU and magnetometer experiments.

### 🔧 Arduino & Sensor Projects
- Arduino circuit experiments and hardware documentation.
- Sensor interfacing and testing with Arduino.
- Motion, orientation, and magnetic-field sensing.
- Joystick and wireless communication experiments.

### ✋ Sign Language Recognition
An AI-powered project that uses **computer vision and machine learning** to recognize hand gestures and convert sign language into **text and speech**.
